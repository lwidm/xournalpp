## Setup

### Linux

- check if the directory `~\.config\xournalpp`exists. If so delete it.
- Go to directory `~\config\xournalpp`
- Clone this repo
  ```zsh
  git clone https://github.com/lwidm/xournalpp
  ```
- Start xournalpp

### Windows

- check if the directory `~\Appdata\Local\xournalpp`exists. If so delete it.
- Go to directory `~\Appdata\Local\xournalpp`
  ```PowerShell
  cd ~\Appdata\Local
  ```
- Clone this repo
  ```PowerShell
  git clone https://github.com/lwidm/xournalpp
  ```
- Start xournalpp
